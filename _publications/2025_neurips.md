A lightweight framework that transforms intermediate tokens via the Discrete Fourier Transform, using low-frequency structural priors for robust token clustering and merging — up to 25% lower inference latency on Stable Diffusion v1.5 with comparable visual fidelity, with theoretical error bounds for frequency-domain merging.
